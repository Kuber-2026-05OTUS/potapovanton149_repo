Для задания со * необходимо было выполнить ``strace `` для корневого процесса `nginx`, но проблема в том что distroless-образ кастрированный и не содержит баша и прочего, соответственно `kubectl exec` не запустится.

Единcтвенное решение - эфимерный контейнер через `kubectl debug`.

По умолчанию эфимерный контейнер создается со своим линукс неймспесами. Для того что бы использовались общие неймспейсы добавляемфлаг `--target=nginx`.

Далее нашему контейнеру нужно выдать капабилитес `CAP_SYS_PTRACE`, для этого юзаем флаг `--profile=sysadmin`.

Важно, всю сетевую работу делает воркер процесс, поэтому что бы выдеть стек трейс вызовов цепляемся сразу на два процесса - `strace -f -p 1 -p 7`

В отдельном терминале форвордим и курлим, далее наблюдаем уже стек трейс вызовов (см. img5.png).

Итого общая команда 

```kubectl -n homework debug -it nginx-distroless \
  --image=nicolaka/netshoot:latest \
  --target=nginx \
  --profile=sysadmin \
  -- bash
```
